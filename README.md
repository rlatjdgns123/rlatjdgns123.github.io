# 기록의 여백

GitHub Pages에서 바로 배포할 수 있는 한국어 개인 블로그 첫 디자인입니다.

## GitHub Pages 배포

1. 이 폴더 내용을 `사용자이름.github.io` 저장소에 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
3. `main` 브랜치와 `/ (root)` 폴더를 선택해 저장합니다.
4. 몇 분 뒤 `https://사용자이름.github.io`에서 확인합니다.

현재는 디자인 시안입니다. 글을 실제 Markdown 파일로 관리하는 구조와 카테고리별 글 목록은 다음 단계에서 연결하면 됩니다.
